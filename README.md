# 🎨 お絵描き当てゲーム (Drawing Guessing Game)

スマホのブラウザで手軽に遊べる、2人プレイ専用のお絵描き当て（お絵描きロジック）ゲームです！✨

## ✨ 特徴 (Features)
- **2人プレイ専用:** 1台のスマホを交代でパスしながら遊ぶパス＆プレイ仕様！
- **選べるお題システム:** 「かんたん」「ふつう」「むずかしい」の3つの難易度からお題を選べます。
- **多言語対応 (Bilingual):** 画面上のボタンでいつでも日本語と英語を切り替え可能！
- **スマホ最適化:** モバイルの画面にぴったり収まるポップでかわいいUIデザイン。

## 🎮 遊び方 (How to Play)
1. **メニュー:** 「2人プレイをはじめる」をタップしてゲームスタート！
2. **お絵描き役:** 端末を受け取ったら、好きなお題（難易度）をひとつ選びます。
3. **お絵描き:** 制限時間内にキャンバスにお題の絵を描きます。「できた！」を押して回答者へ端末を渡します。
4. **回答者:** 描かれた絵を見て、ひみつのお題を当ててテキストで入力！
5. **結果:** 全5ラウンドの合計スコアを競い合おう！

## 🛠️ 使用技術 (Tech Stack)
- HTML5 Canvas
- Tailwind CSS (CDN)
- Vanilla JavaScript
